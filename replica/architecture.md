# Architecture: MacbookNotch (a rebuild of OmniNotch's core features)

Working name `MacbookNotch` until `/replica-brand` picks the real one.
Assumptions, since the user said "proceed" without picking: we build all
tools, in waves, core loop first, and sell it as a paid one-time licence like
the original.

## Stack

The original is a native Mac app with no server, so the web-app defaults of
this skill (Next.js, Postgres, Vercel) don't apply. This is the native
equivalent: one app, no backend of our own, nothing we have to host.

| layer | choice | why |
| --- | --- | --- |
| language / UI | Swift 5.10+, SwiftUI for views, AppKit for the notch window | the only way to get a borderless panel over the menu bar, drag and drop, and "lightest" memory use. Electron would be 10× the size |
| minimum OS | macOS 14 Sonoma, Apple silicon + Intel (universal binary) | matches the original. macOS 26-only features sit behind `#available` |
| project | XcodeGen `project.yml` → `.xcodeproj` generated on the Mac | the project file stays reviewable text. Hand-editing `.pbxproj` from a Linux container is how builds break |
| code layout | app target `MacbookNotch` + local Swift package `NotchCore` (models, stores, parsers, converters) | `NotchCore` has no AppKit imports, so it is unit-testable with `swift test` |
| storage | Codable JSON files per tool in `~/Library/Application Support/MacbookNotch/`, blobs (clip images, shelf files) as files next to them | tiny data, no dependency, no migrations engine. SwiftData would be fine too, but it's heavier than we need |
| secrets | Keychain (`kSecClassGenericPassword`, service `app.macbooknotch.<provider>`) | revenue API keys and the licence key never go in JSON or UserDefaults |
| settings | `UserDefaults` via `@AppStorage`, a SwiftUI `Settings` scene | standard, free |
| auth | none | the original has no account. The licence key is the only identity |
| payments + licences | Lemon Squeezy (merchant of record + License API: activate / validate / deactivate, activation limit 3) | public, documented licence-key API, and it handles VAT. Swap: Dodo Payments (what the original uses) or Paddle + Keygen |
| updates | Sparkle 2 (MIT), EdDSA-signed appcast | "lifetime updates" outside the App Store |
| distribution | Developer ID-signed, notarised DMG from our own site. **Not the Mac App Store** | the sandbox would block AppleScript to Music/Spotify, reading AI CLI logs, the volume-key event tap and the global mouse monitor |
| launch at login | `SMAppService.mainApp` | the macOS 13+ API, no helper app |
| dock / menu bar | `LSUIElement = YES` (no Dock icon), small menu bar item for Settings / Quit | standard for notch apps |
| telemetry | none. Crash logs only if the user sends them | "no telemetry" is part of the pitch |
| CI | GitHub Actions `macos-14` runner: `xcodegen`, `xcodebuild build test`, `swift test` for `NotchCore` | this cloud container is Linux with no Swift toolchain, so CI is where the code actually gets compiled until you build on your Mac |

## Schema

There is no database. These are the local stores: 11 JSON stores, one
blob folder per kind, and Keychain items. Access rules: single user, local
files with 0600 permissions, secrets in the Keychain only. The full Swift
model definitions are in `replica/schema.md`.

| store | file | holds | limit / retention |
| --- | --- | --- | --- |
| Shelf | `shelf.json` + `Shelf/<uuid>/<filename>` | `ShelfItem` | copied in on drop; deleted after retention (default 24 h, setting) |
| Clipboard | `clipboard.json` + `Clips/<uuid>.png` | `Clip` | newest first, max 200 (setting), de-duplicated by hash |
| Notes | `notes.json` | `Note` | — |
| To-dos | `todos.json` | `TodoItem` | completed items cleared after 7 days (guess) |
| Timers | `timers.json` | `TimerPreset`, `ActiveTimer` | active timer survives a relaunch (stores `endsAt`, not "seconds left") |
| Stocks | `stocks.json` | `Ticker` watchlist + last quote | — |
| Weather | `weather.json` | last `WeatherSnapshot` | refreshed every 30 min |
| AI usage | `ai-usage.json` | `ProviderUsage` per provider | refreshed every 5 min |
| Revenue | `revenue.json` | `RevenueSource` (no keys), `RevenueSnapshot` | refreshed every 15 min; keys in Keychain |
| Teleprompter | `scripts.json` | `Script` | — |
| Licence | Keychain `app.macbooknotch.licence` | key, instance id, last validated | offline grace: 30 days between validations |
| Chat | memory only | `ChatMessage` | cleared on quit. Nothing about prompts is written to disk |

Hard constraints the recon found, and where they're enforced:

- **Password-manager clips are never stored.** Check before saving: skip any pasteboard item that carries `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType` or `org.nspasteboard.AutoGeneratedType`, plus a user deny-list of apps (1Password, Bitwarden, Keychain Access by default).
- **A shelf file outlives its source.** It is copied in on drop, so moving or deleting the original doesn't break it. Over a size cap (default 2 GB) we keep a bookmark instead, and the UI says "linked".
- **3 Macs per licence** is enforced by the licence provider's activation limit, not by our code.

## "API": internal services and external calls

The app is a set of services owned by one `AppModel`. Each tool view reads
one service. Flows are from `recon.md`.

| service | does | permission / entitlement | external calls | flow |
| --- | --- | --- | --- | --- |
| `NotchWindowController` | creates one `NSPanel` per screen, positions it over the notch or draws a floating notch, handles hover, open/close animation, drag-over | none | — | F01, F02 |
| `ScreenGeometry` | notch rect from `NSScreen.safeAreaInsets.top` + `auxiliaryTopLeftArea` / `auxiliaryTopRightArea`; fallback size when there's no notch | none | — | F01 |
| `NowPlayingService` | title, artist, art, position, play/pause/next/prev/seek | Automation (Apple Events) per player | AppleScript to Music.app and Spotify | F03 |
| `ShelfService` | accept drops, copy files in, expire, AirDrop via `NSSharingService(named: .sendViaAirDrop)`, drag back out | none | — | F02 |
| `ClipboardService` | poll `NSPasteboard.general.changeCount` every 0.5 s, store, re-copy, delete | none (see "parts that bite" for macOS 26 paste privacy) | — | F04 |
| `ChatService` | Ask Omni: `LanguageModelSession` streaming, availability check | macOS 26 + Apple Intelligence on | on-device only | F05 |
| `TimerService` | countdowns, notch live activity, finish chime + `UNUserNotification` | Notifications | — | F06 |
| `EventsService` | today's calendar events, reminders list / complete | Calendars, Reminders (EventKit full access) | — | — |
| `SystemStatsService` | CPU (`host_processor_info`), memory (`host_statistics64`), net bytes (`getifaddrs`); only polls while visible | none | — | — |
| `PowerService` | Keep Awake via `IOPMAssertionCreateWithName(kIOPMAssertionTypePreventUserIdleSystemSleep)`, optional timed | none | — | F10 |
| `VolumeService` | read/set volume via CoreAudio; intercept volume keys with a `CGEventTap` to show our HUD instead of the system one | Accessibility | — | — |
| `WeatherService` | current conditions for the current or chosen city | Location (optional) | WeatherKit (Apple Developer Program, attribution required) | — |
| `StocksService` | quotes for a watchlist | none | Finnhub `/quote` with the user's own free key (could-have) | — |
| `AIUsageService` | usage and limits per AI coding CLI | file access to `~/.claude`, `~/.codex` | **default: none**. Parses the CLIs' own local session logs. Opt-in: provider usage endpoints with the token the CLI already stored | F07 |
| `RevenueService` | today's gross per source, summed by currency | none | Stripe `GET /v1/balance_transactions?created[gte]=`, Shopify Admin `orders`, Lemon Squeezy `orders`, Gumroad `sales`, Dodo `payments`, Polar `orders`, Paddle `transactions`, all with the user's own **read-only** keys | F08 |
| `CameraService` | Quick Mirror preview (`AVCaptureSession`), runs only while visible | Camera | — | — |
| `TeleprompterService` | scrolls a script directly under the camera (which is in the notch) | none | — | — |
| `ConverterService` | units via `Foundation.Measurement`; currency | none | Frankfurter (ECB rates, no key), cached daily | — |
| `EmojiService` | search the bundled Unicode emoji list (CLDR names), copy to the clipboard | none | — | — |
| `LicenceService` | activate / validate / deactivate | none | Lemon Squeezy `POST /v1/licenses/activate`, `/validate`, `/deactivate` | F09 |
| `UpdateService` | Sparkle | none | our appcast URL | — |

Webhooks in: none (no server). Webhooks out: none.

Background jobs, all in-process timers, all paused while the lid is closed or
the screen is asleep:

| job | schedule | does |
| --- | --- | --- |
| shelf cleanup | launch + hourly | delete items past `expiresAt` |
| clipboard poll | 0.5 s | `changeCount` check (a cheap integer read) |
| weather refresh | 30 min, and on panel open if older than that | |
| stocks refresh | 1 min while the Stocks tool is visible, else 15 min | |
| AI usage refresh | 5 min | re-parse new log lines only (keep file offsets) |
| revenue refresh | 15 min, and on panel open | |
| licence validate | on launch if last check > 7 days old, 30-day offline grace | |
| currency rates | daily | |

## The parts that bite

- **Notch geometry.** Notch width differs by model. Compute it from `auxiliaryTopLeftArea` / `auxiliaryTopRightArea` and never hard-code it. External displays have no notch, so we use the floating notch there or hide (setting: "show on: built-in only / all displays / screen with the mouse").
- **Full-screen apps and Spaces.** Panel `collectionBehavior` `[.canJoinAllSpaces, .stationary, .fullScreenAuxiliary, .ignoresCycle]`. In full screen the menu bar hides, so we hide the closed notch too but keep hover-to-reveal (setting).
- **Hover without stealing focus.** `NSPanel` with `.nonactivatingPanel`, so opening the notch never pulls focus from the app you're typing in. Only text tools (Ask Omni, notes, to-dos) make the panel key, and only on click.
- **Hover debounce.** Open after ~100 ms of hover and close ~300 ms after leaving, but never close while a drag is in progress or a text field is focused. (The original's 2.0 was mostly about this feel. See the maker's "quieter, faster" note.)
- **Now Playing.** There is no public, system-wide now-playing API, and Apple locked the private MediaRemote framework in macOS 15.4. Our plan is AppleScript to Music and Spotify: public, but it covers only those two and needs an Automation prompt per app. Browsers (YouTube etc.) are out for v1. Revisit with an open-source adapter only after checking its licence.
- **Clipboard privacy on macOS 26.** Newer macOS versions add user-facing controls and alerts for apps that read the pasteboard. Verify on macOS 26 before shipping; the 0.5 s poll may need to become "read only on change".
- **AI usage = credentials.** Default mode reads only the CLIs' local usage logs and never touches tokens. The opt-in mode uses the token the CLI already stored on the Mac, calls only the provider's own endpoint, and never logs or exports it. Those endpoints are undocumented and will change, so each provider is a small adapter with an "unavailable" state.
- **Ask Omni availability.** `SystemLanguageModel.default.availability` can be unavailable (older OS, Intel, Apple Intelligence off, model downloading). Each case gets its own message, and on macOS 14/15 the tool is hidden.
- **Time zones.** Calendar and revenue "today" use the user's current time zone and handle the midnight rollover. Timers store an absolute `endsAt`, so sleep and DST don't drift them.
- **Money.** Integer minor units plus a currency per source. Never add different currencies together. Show per currency, or convert with the daily ECB rate and label it "≈".
- **Rate limits.** Revenue and stock APIs have per-key limits. Back off exponentially and show the stale time.
- **Idempotency.** Licence activation: store the instance id before showing success, and retrying with the same `instance_name` (machine name + hardware UUID hash) never burns a second slot.
- **Memory / CPU budget (the "lightest" claim).** Target < 60 MB resident and ~0% idle CPU when closed. No polling for anything not visible except clipboard, timers and the scheduled jobs above. Camera and stats stop when hidden.
- **Permissions UX.** Ask for each permission when its tool is first opened, never all at launch. Every tool works or explains itself when a permission is denied.
- **Licence offline.** 30-day grace since the last successful validation, then a gentle nag. Never brick the app mid-task.

## Build order

**Milestone 0, vertical slice (proves the stack).**
S01, S03, S06, S02 (music), plus the CI workflow.
The notch panel on the built-in display, hover open/close with animation,
Now Playing via AppleScript with album art and controls, the compact music
activity in the closed notch, menu bar item with Quit, launch at login.
Stores: none yet. Done when it opens smoothly on your MacBook and controls
Apple Music.

**Milestone 1, must-haves (13 rows).**
- Shell: floating notch on non-notch screens, multi-display setting, tool switcher, Settings window (enable/reorder tools, hover delays, show-on display, launch at login). S01–S04, S26.
- File shelf + AirDrop + retention + ⌥-delete. S04, S08. Store: Shelf.
- Clipboard history + password-manager skip + ⌥-delete. S07. Store: Clipboard.

**Milestone 2, should-haves (12 rows).**
- 2a, everyday: Timers (S09), Keep Awake (S23), System stats (S16), Notes (S13), To-dos (S12).
- 2b, Apple data: Calendar (S10), Reminders (S11), Weather (S14).
- 2c, the harder ones: Volume HUD (S24), Ask Omni (S05), Live AI usage for Claude / Codex / Copilot (S17).
- 2d, paid: licence activation (S28), onboarding/permissions (S27), Sparkle updates. This must ship before anything is sold.

**Milestone 3, could-haves (7 rows).**
Stocks (S15), Revenue (S18), Teleprompter (S19), Quick Mirror (S20), Emoji (S21), Converter (S22), Cursor/Grok usage.

**Milestone 4, fixes from `/replica-entrepreneur`.** Run it before Milestone 3 so the could-haves are picked by what users actually miss, not by what the original happens to have.
